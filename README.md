# XO AI 🎮

A simple Tic-Tac-Toe game built with Python, featuring an AI opponent powered by the Minimax algorithm.

## Features
- Play against an AI.
- AI chooses its moves using Minimax.
- Win and draw detection.
- Play again without restarting the program.

## Project Structure

```text
xo-ai/
├── main.py
├── game.py
├── ai.py
└── README.md
```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/MehdiD0/xo-ai.git
```

2. Navigate to the project:

```bash
cd xo-ai
```

3. Run the game:

```bash
python main.py
```
