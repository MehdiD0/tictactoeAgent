# XO AI 🎮

A simple Tic-Tac-Toe game built with Python, featuring an AI opponent powered by the Minimax algorithm.

## Features
- Play against an AI.
- AI chooses its moves using Minimax.
- Win and draw detection.
- Play again without restarting the program.

## Project Structure

```text
tictactoeAgent/
├── main.py
├── game.py
├── ai.py
└── README.md
```

## How to Run

.Clone the repository:

```bash
git clone https://github.com/MehdiD0/tictactoeAgent.git
```

.Run the game:

```bash
python main.py
```
